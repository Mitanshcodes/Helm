### B. Evaluations: the biggest gap (slides and Devpost show "not measured" until this is done)
Follow `eval/PROTOCOL.md`; it is up to date for the new dashboard. Minimum: 3 participants (team members are fine;
the slides state that no participant had a motor impairment). Per participant, about 35 min, in this order:
1. **Setup:** New profile with their name, plus Teach a move with the everyday face.
2. **Test 2, false triggers:**
   - Record with `python -m helm --player NAME --no-server --seconds 180 --record eval/results/rec_NAME.npz`:
     1 min reading aloud, 1 min chatting, 1 min watching a video.
   - Score it straight away with `python eval/false_triggers.py eval/results/rec_*.npz`.
3. **Test 3, target test:** `eval/target_test.html` with the separate profiles `NAME_c` (full setup, small moves)
   and `NAME_d` (`?quick=1`). Keep steering sensitivity at 1.0×. Download each CSV into `eval/results/`.
4. **Test 1, latency:**
   - Film `eval/latency.html` at 240 fps on a phone: 20 eyebrow raises, then 20 presses on a real controller.
   - Count the frames into `eval/results/latency.csv` (format in the protocol).
5. **Participants log:** add a row to `eval/results/participants.csv`: `loto_accuracy` (the nod's "% recognized",
   as a fraction) and `launch_to_race_s` (stopwatch from `python -m helm` to the kart moving).

Then run `python eval/analysis.py`:
- It prints every number with n and a baseline, and writes `eval/results/*.png` and `headline.json`.
- It prints a block for `ui/src/results.ts`. Give that block and `headline.json` to P4 for the slides, README and
  Devpost.
- Commit the `eval/results/` files. Never put an estimate on a slide.

## Decisions
- Mapper timers run on the frame's `t_infer_ns`, so `--replay` reproduces the same button stream.
- Breath gestures get `min_hold_ms=0`; `auto` is a base layer that axes and gestures override.
- `make_gamepad("auto")` tries vgamepad then keyboard only on Windows; elsewhere it returns
  NullPad, so development on macOS cannot type into the focused window.
- Refractory begins on gesture release; minimum hold starts after refractory expires.
- Tap output lasts `config.TAP_MS` even after early gesture release; sustained input cannot retrigger.
- BreathDetector takes host milliseconds and positive baseline-relative pressure maxima. Serial
  owns baseline estimation; freeze updates while detector.active. Helpers are not wired yet.
