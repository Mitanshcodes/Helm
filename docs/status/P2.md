- Bench session on the real board (2026-11-14): **breath verified end to end on hardware.**
  Rest sits mid-rail at ~2390 mV, rest noise 12-40 mV peak to peak, 2 mV ADC steps, 2207 lines
  parsed with 0 unparseable. A committed breath swings the sensor nearly rail to rail: hard sip
  reached 22 mV (displacement 2360), hard puff 4792 mV (2410).
- Retuned `BREATH_MAX_SIP_MV` 400 -> 1800 and `BREATH_MAX_PUFF_MV` 400 -> 1000 from those
  measurements. The old 400 mV placeholders were about 6x too SMALL, not too large: level would
  have saturated on a light breath and the demo's analog sip-brake would have had no travel at all,
  slamming fully on from a gentle sip. The two scales are asymmetric on purpose -- sip measured
  2360/2360/1766 mV and is repeatable, puff measured 2410/1024/1078 mV and is not, so puff is
  scaled near the low end of its spread or an ordinary puff never clears `BREATH_HARD` and the
  latched throttle silently fails to fire.
- Verified through the real `demo` profile, serial -> `SipPuff` -> `Mapper` -> `ControlState`:
  rest LT 0.00; gentle sip level -0.17 -> LT 0.03 (proportional); hard sip level -1.00 -> LT 1.00;
  three hard puffs toggled RT 1.00 / 0.00 / 1.00 with exactly one `hard_puff` event each.
- Noise margin is now comfortable: 40 mV of rest noise against a 450 mV soft-sip threshold, over
  10x, so the earlier worry that a cough could brake the kart is settled.
- Events are release-classified, so the throttle latches when the puff STOPS, about 200 ms later

- `fast_breath` now pins `BREATH_MAX_*_MV` for the serial-plumbing tests. Two of my own tests went

## Decisions
- Mapper timers run on the frame's `t_infer_ns`, so `--replay` reproduces the same button stream.
- Breath gestures get `min_hold_ms=0`; `auto` is a base layer that axes and gestures override.
- `make_gamepad("auto")` tries vgamepad then keyboard only on Windows; elsewhere it returns
  NullPad, so development on macOS cannot type into the focused window.
- Refractory begins on gesture release; minimum hold starts after refractory expires.
- Tap output lasts `config.TAP_MS` even after early gesture release; sustained input cannot retrigger.
- BreathDetector takes host milliseconds and positive baseline-relative pressure maxima. Serial
  owns baseline estimation; freeze updates while detector.active. Helpers are not wired yet.
