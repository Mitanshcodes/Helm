## Decisions
- Commands from the server go into a small locked list the pipeline drains each frame; events the
  same way in the other direction. Frame data still uses latest-value slots only.
- A new calibrate or record command replaces whichever of the two is active.
- `ReplaySource` re-stamps timestamps to now and keeps the recorded vision delay, so latency
  numbers stay meaningful in replay.
- `--seconds` only applies with `--no-server` for now.
- `snapshot()["profile"]["calibrated"]` is `null` until a calibration exists.
- `calibration.default_calibration(player)` is the uncalibrated default (15 degrees each way).
