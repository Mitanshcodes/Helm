## Decisions
- `ONE_EURO_BETA = 1.0`, not the spec's 0.01: on normalized axes 0.01 lagged a head turn ~270 ms in
  simulation; 1.0 lags ~1 frame with rest jitter well inside the dead zone.
- `Calibration.reliable` always includes `eyeBlinkLeft/Right` (pause gesture; never prompted), and quick mode
  also trusts `browInnerUp`, `jawOpen` (judge profile). Config: `ASSUMED_RELIABLE`, `QUICK_ASSUMED_RELIABLE`.
- Quick-mode auto-range only samples excursions beyond half the current limit, so time near neutral does
  not hold the 95th percentile down.
- Coach default model `anthropic:claude-opus-5-5`; `coach.check` = `profiles.validate_mapping` plus the
  coach's own checks, so submitted mappings are safe even while P2's validator is a stub.
- Commands from the server go into a small locked list the pipeline drains each frame; events the same way back.
- A new calibrate or record command replaces whichever of the two is active.
- `ReplaySource` re-stamps timestamps to now and keeps the recorded vision delay.
- README pipeline section (item 10) belongs in P4's README: pass text to P4 rather than editing it.
