## Decisions
- The LCD brief came with its own draft protocol (port 8765, `scores`, `eyes_closed_s`, commands like
  `skip_calibration`). The UI stays on the real protocol of spec section 8; held eye time is measured in
  the UI from the pause gesture's activation crossing its `on` threshold.
- Pause is Helm's own state, not a pad button, so the pad drawing does not light Menu for it; the legend
  says "Close eyes 2 s (pauses Helm)".
- No claim that "talking won't press anything" in the message box: that is only true once negatives exist.
- Sound in the footer switches both spoken prompts and clicks; the separate toggles were removed.
- The server mirrors the preview and landmarks, so the UI does not mirror again.
- `set_mapping` has no success reply: 600 ms without an `error` event counts as applied.
- Only the main window auto-starts calibration (after the intro); the overlay never does.
- Local dev machine has Python 3.14 only; a `.venv` on 3.14 runs all tests and the smoke run.
